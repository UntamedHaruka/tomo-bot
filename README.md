# 🤖 Tomo Bot

A Discord bot that matches users randomly in a server and gives conversation prompts.
## 🤖 Add Tomo to your server

[![Invite Bot](https://img.shields.io/badge/Invite-Tomo-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.com/oauth2/authorize?client_id=1500104135910096916&permissions=67584&integration_type=0&scope=bot)

## Features
- 🎯 Random user matching
- 💬 Conversation prompts
- ⏳ Cooldown system
- 📖 Help command

## Commands
- `t!match`
- `t!help`

- Node.js
- discord.js
